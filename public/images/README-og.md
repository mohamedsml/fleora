# Image de partage social

`og-fleora.jpg` est une **image provisoire** — un simple aplat aux couleurs de
la marque, généré automatiquement.

## À remplacer

Format attendu : **1200 × 630 px**, JPEG, moins de 300 Ko.

C'est le visuel qui apparaît quand un lien du site est partagé sur Facebook,
Messenger, LinkedIn ou WhatsApp. Une photo de création bien cadrée convertit
nettement mieux qu'un aplat — ces canaux sont les premiers points de découverte
pour ce type de produit.

Les fiches créations et les pages occasions utilisent déjà **leur propre photo**
quand elle existe : cette image ne sert que pour l'accueil et les pages sans
visuel.

Après remplacement, vider le cache des aperçus :
- Facebook : https://developers.facebook.com/tools/debug/
- LinkedIn : https://www.linkedin.com/post-inspector/
