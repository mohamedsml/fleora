# Champs des occasions à saisir en production

Administration → Contenu du site → Occasions → modifier chaque occasion.

Les onglets **Français** et **English** portent chacun leurs champs ; l’icône se trouve
dans la section **Affichage**.

> Les titres Google restent sous 60 caractères et les descriptions sous 160 : au-delà,
> Google tronque. Le nom « Fleora » n’y figure pas, le site le préfixe déjà.

Généré depuis la base locale le 11 septembre 2026.

## Raccourci

Plutôt que de tout saisir à la main, une commande applique ces textes sur le serveur :

```
cd ~/domains/fleora.ca/fleora
/opt/alt/php83/usr/bin/php artisan fleora:textes-occasions --remplacer
```

Sans `--remplacer`, seuls les champs vides sont remplis — aucune saisie existante n’est écrasée.
